Como instalar:
1. Faça backup do projeto atual.
2. Substitua a pasta src do seu projeto pela pasta src deste pacote.
3. Copie public/images para dentro da pasta public do seu projeto.
4. Não apague imagens antigas antes de testar.
5. Faça commit no GitHub.
6. Aguarde o deploy automático no Vercel.
