# Paola Leite Eikeset — Website V2

Projeto React + Vite completo, sem fotografia de livro.

## Publicar no GitHub
1. Descompacte o ficheiro.
2. No repositório, substitua todos os ficheiros pela estrutura deste projeto.
3. Confirme que as pastas `src` e `public/images` foram carregadas.
4. Faça `Commit changes`.
5. A Vercel fará o deploy automaticamente.

## Integrações
- Formspree: configurado em `src/data/content.js`
- Google Calendar: configurado em `src/data/content.js`
- WhatsApp: configurado em `src/data/content.js`
